## 2. Stack and queue

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class StackQueueDemo {
    public static void main(String[] args) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(1); stack.push(2); stack.push(3);
        System.out.println(stack.pop());     // 3 (last in, first out)

        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(1); queue.offer(2); queue.offer(3);
        System.out.println(queue.poll());    // 1 (first in, first out)
    }
}
```

## 3. Hash table

A hash function converts a key into an array index. Two keys that map to the same index cause a **collision**, handled by chaining (a list per bucket) or open addressing.

```java
import java.util.HashMap;
import java.util.Map;

public class HashDemo {
    public static void main(String[] args) {
        Map<String, Integer> marks = new HashMap<>();
        marks.put("Pema", 82);
        marks.put("Tashi", 74);
        System.out.println(marks.get("Pema"));            // 82
        System.out.println(marks.containsKey("Dorji"));   // false
    }
}
```

The average cost is O(1), but the worst case is O(n) if many keys collide. A good hash function and a sensible load factor keep it near O(1).

## 4. Binary search tree (BST)

For every node, values in the left subtree are smaller and values in the right subtree are larger.

```java
public class BST {
    static class Node {
        int key; Node left, right;
        Node(int key) { this.key = key; }
    }

    Node root;

    void insert(int key) { root = insert(root, key); }

    private Node insert(Node node, int key) {
        if (node == null) return new Node(key);
        if (key < node.key) node.left = insert(node.left, key);
        else if (key > node.key) node.right = insert(node.right, key);
        return node;
    }

    boolean contains(int key) {
        Node cur = root;
        while (cur != null) {
            if (key == cur.key) return true;
            cur = key < cur.key ? cur.left : cur.right;
        }
        return false;
    }

    void inorder(Node node) {                  // visits keys in sorted order
        if (node == null) return;
        inorder(node.left);
        System.out.print(node.key + " ");
        inorder(node.right);
    }

    public static void main(String[] args) {
        BST t = new BST();
        for (int k : new int[]{50, 30, 70, 20, 40, 60, 80}) t.insert(k);
        t.inorder(t.root);                      // 20 30 40 50 60 70 80
        System.out.println();
        System.out.println(t.contains(60));     // true
        System.out.println(t.contains(65));     // false
    }
}
```

**Traversals:** inorder (left, node, right) gives sorted output; preorder (node, left, right) copies a tree; postorder (left, right, node) deletes a tree. An unbalanced BST degrades to O(n), which is why balanced trees (AVL, red-black) exist.

## 5. Heap and priority queue

A min-heap is a complete binary tree where each parent is smaller than its children, so the smallest element is always at the root.

```java
import java.util.PriorityQueue;

public class HeapDemo {
    public static void main(String[] args) {
        PriorityQueue<Integer> pq = new PriorityQueue<>();
        pq.add(40); pq.add(10); pq.add(30);
        System.out.println(pq.poll());   // 10
        System.out.println(pq.poll());   // 30
    }
}
```

## 6. Graphs: BFS and DFS

A graph is a set of vertices connected by edges. An adjacency list stores, for each vertex, its neighbours.

```java
import java.util.*;

public class GraphDemo {
    static void bfs(Map<Integer, List<Integer>> g, int start) {
        Set<Integer> seen = new HashSet<>();
        Queue<Integer> q = new ArrayDeque<>();
        q.add(start); seen.add(start);
        while (!q.isEmpty()) {
            int v = q.poll();
            System.out.print(v + " ");
            for (int n : g.getOrDefault(v, List.of())) {
                if (seen.add(n)) q.add(n);
            }
        }
        System.out.println();
    }

    static void dfs(Map<Integer, List<Integer>> g, int v, Set<Integer> seen) {
        if (!seen.add(v)) return;
        System.out.print(v + " ");
        for (int n : g.getOrDefault(v, List.of())) dfs(g, n, seen);
    }

    public static void main(String[] args) {
        Map<Integer, List<Integer>> g = new HashMap<>();
        g.put(1, List.of(2, 3));
        g.put(2, List.of(4));
        g.put(3, List.of(4));
        g.put(4, List.of());
        bfs(g, 1);                          // 1 2 3 4
        dfs(g, 1, new HashSet<>());         // 1 2 4 3
        System.out.println();
    }
}
```

| | BFS | DFS |
|---|---|---|
| Uses | Queue | Stack / recursion |
| Finds | Shortest path (unweighted) | Any path, cycle detection, topological order |
| Time | O(V + E) | O(V + E) |

## 7. Recursion and merge sort

Every recursive method needs a **base case** (stops the recursion) and a **recursive case** that moves toward it.

```java
import java.util.Arrays;

public class MergeSortDemo {
    static int[] mergeSort(int[] a) {
        if (a.length <= 1) return a;                       // base case
        int mid = a.length / 2;
        int[] left = mergeSort(Arrays.copyOfRange(a, 0, mid));
        int[] right = mergeSort(Arrays.copyOfRange(a, mid, a.length));
        return merge(left, right);
    }

    static int[] merge(int[] l, int[] r) {
        int[] out = new int[l.length + r.length];
        int i = 0, j = 0, k = 0;
        while (i < l.length && j < r.length) out[k++] = l[i] <= r[j] ? l[i++] : r[j++];
        while (i < l.length) out[k++] = l[i++];
        while (j < r.length) out[k++] = r[j++];
        return out;
    }

    public static void main(String[] args) {
        System.out.println(Arrays.toString(mergeSort(new int[]{38, 27, 43, 3, 9, 82, 10})));
        // [3, 9, 10, 27, 38, 43, 82]
    }
}
```

| Sort | Best | Average | Worst | Space | Stable |
|---|---|---|---|---|---|
| Merge sort | O(n log n) | O(n log n) | O(n log n) | O(n) | Yes |
| Quick sort | O(n log n) | O(n log n) | O(n²) | O(log n) | No |
| Insertion sort | O(n) | O(n²) | O(n²) | O(1) | Yes |
