## 1. Why study data structures and algorithms?

A **data structure** is a way of organising data so that it can be used efficiently. An **algorithm** is a step-by-step procedure for solving a problem. The same task can be solved in many ways, and the choice of structure and algorithm decides how fast the program runs and how much memory it uses.

Example: searching 1,000,000 sorted numbers. Linear search may need up to 1,000,000 comparisons, while binary search needs about 20.

## 2. Big-O notation (introduction)

Big-O describes how the work grows as the input size `n` grows. Constants and smaller terms are ignored.

| Notation | Name | Example |
|---|---|---|
| O(1) | Constant | Read `arr[i]` |
| O(log n) | Logarithmic | Binary search |
| O(n) | Linear | Loop through an array once |
| O(n log n) | Linearithmic | Merge sort |
| O(n²) | Quadratic | Nested loops, bubble sort |

```java
// O(n): one pass
int sum = 0;
for (int x : arr) sum += x;

// O(n^2): a loop inside a loop
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        count++;
```

## 3. Arrays and linked lists

| Operation | Array | Singly linked list |
|---|---|---|
| Access by index | O(1) | O(n) |
| Insert / delete at the start | O(n) (shifting) | O(1) |
| Insert / delete at the end | O(1) if space exists | O(n) without a tail pointer |
| Memory | Contiguous, fixed size | Scattered nodes, extra pointer per node |

```java
class Node {
    int data;
    Node next;
    Node(int data) { this.data = data; }
}
```

Adding a node at the head:

```java
Node head = null;
Node n = new Node(10);
n.next = head;   // new node points at the old head
head = n;        // head now points at the new node
```

## 4. Searching

### Linear search – O(n)

```java
static int linearSearch(int[] a, int target) {
    for (int i = 0; i < a.length; i++) {
        if (a[i] == target) return i;
    }
    return -1;
}
```

### Binary search – O(log n), requires a sorted array

```java
static int binarySearch(int[] a, int target) {
    int low = 0, high = a.length - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;   // avoids integer overflow
        if (a[mid] == target) return mid;
        else if (a[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
```

**Trace:** `a = [2, 5, 8, 12, 16, 23]`, `target = 12`

| Step | low | high | mid | a[mid] | Decision |
|---|---|---|---|---|---|
| 1 | 0 | 5 | 2 | 8 | 8 < 12, so `low = 3` |
| 2 | 3 | 5 | 4 | 16 | 16 > 12, so `high = 3` |
| 3 | 3 | 3 | 3 | 12 | Found at index 3 |

## 5. First sorting algorithms

```java
static void bubbleSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        boolean swapped = false;
        for (int j = 0; j < a.length - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
                swapped = true;
            }
        }
        if (!swapped) break;       // already sorted
    }
}
```

| Algorithm | Best | Average | Worst | Extra space |
|---|---|---|---|---|
| Bubble sort | O(n) with the early exit | O(n²) | O(n²) | O(1) |
| Selection sort | O(n²) | O(n²) | O(n²) | O(1) |
