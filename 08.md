## 1. Key ideas from the course

### Focused and diffuse modes of thinking
- **Focused mode:** concentrated attention on a problem you already have a route into.
- **Diffuse mode:** a relaxed state where the brain makes wider connections in the background.
- Hard problems often need both. Work on the problem, step away (walk, rest, sleep), then return.

### Procrastination and the Pomodoro technique
- Procrastination is often avoiding discomfort, not laziness.
- Pomodoro: 25 minutes of focused work with the phone away, then a short reward break. This trains starting without waiting for motivation.

### Chunking
A chunk is a unit of knowledge bound together by meaning. Build chunks by focusing on the idea, understanding why it works, then practising until it is automatic. Example: a loop, then a nested loop, then "search a 2D array" becomes one chunk.

### Memory
- **Working memory** holds a few items briefly.
- **Long-term memory** is built through repetition spaced over time.

### Practice techniques

| Technique | What it is | Example in my technical study |
|---|---|---|
| Active recall | Test yourself before looking at notes | Write a linked-list insert from memory |
| Spaced repetition | Revisit material over increasing gaps | Review DSA notes on day 1, 3, 7, 14 |
| Interleaving | Mix different problem types | Alternate sorting, trees and hashing problems |
| Illusion of competence | Feeling you know it because it looks familiar | Re-reading a solution is not the same as solving it |
| Deliberate practice | Focus on the hardest parts | Redo the recursion problems I got wrong |

### Body and brain
Sleep helps consolidate memory. Exercise supports learning. Avoid all-night cramming.

### Other ideas
- **Einstellung effect:** an early idea blocks a better one. Take a break and restart from scratch.
- **Transfer:** a concept learned in one area (recursion in DSA) helps in another (tree structures in design).

## 2. Study method I will use for technical subjects

```
1. Set one small goal for the session (e.g. "implement BST insert").
2. Read or watch the material once, actively.
3. Close the notes and recall: write or code it from memory.
4. Check against the notes and mark the gaps.
5. Re-test the gaps later using a spaced schedule.
6. Write one line: what worked, what to change.
```
