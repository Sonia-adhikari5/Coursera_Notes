## Problem 1 – Two Sum (hash table)

**Problem:** given an array of integers and a target, return the indexes of two numbers that add up to the target.

**Brute force:** check every pair, O(n²).
**Better idea:** for each number, check whether `target - number` has already been seen. A hash map gives that check in O(1).

```java
import java.util.*;

public class TwoSum {
    static int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> seen = new HashMap<>();   // value -> index
        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];
            if (seen.containsKey(need)) return new int[]{seen.get(need), i};
            seen.put(nums[i], i);
        }
        return new int[]{-1, -1};
    }

    public static void main(String[] args) {
        System.out.println(Arrays.toString(twoSum(new int[]{2, 7, 11, 15}, 9)));  // [0, 1]
    }
}
```

**Trace:** `nums = [2, 7, 11, 15]`, `target = 9`

| i | nums[i] | need | seen before | Action |
|---|---|---|---|---|
| 0 | 2 | 7 | {} | store 2 → 0 |
| 1 | 7 | 2 | {2→0} | found, return [0, 1] |

**Complexity:** time O(n), space O(n).
**Edge cases:** no valid pair (returns `[-1, -1]`), duplicates such as `[3, 3]` with target 6 (works because the lookup happens before the store).

## Problem 2 – Valid Parentheses (stack)

**Problem:** given a string of `()[]{}`, decide whether the brackets are correctly matched and nested.

**Idea:** push each opening bracket; for each closing bracket, the top of the stack must be its matching opener.

```java
import java.util.*;

public class ValidParentheses {
    static boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) return false;
                char open = stack.pop();
                if ((c == ')' && open != '(') ||
                    (c == ']' && open != '[') ||
                    (c == '}' && open != '{')) return false;
            }
        }
        return stack.isEmpty();                 // leftover openers mean invalid
    }

    public static void main(String[] args) {
        System.out.println(isValid("{[()]}"));  // true
        System.out.println(isValid("([)]"));    // false
        System.out.println(isValid("(("));      // false
    }
}
```

**Trace:** `"{[()]}"`

| Char | Action | Stack (top on right) |
|---|---|---|
| `{` | push | { |
| `[` | push | { [ |
| `(` | push | { [ ( |
| `)` | pop `(`, matches | { [ |
| `]` | pop `[`, matches | { |
| `}` | pop `{`, matches | empty → valid |

**Complexity:** time O(n), space O(n).
**Edge cases:** empty string (valid), starts with a closer, extra openers left at the end.

## Problem 3 – Reverse a Linked List

**Problem:** reverse a singly linked list.

**Idea:** walk the list and flip each `next` pointer, keeping track of the previous node so the rest of the list is not lost.

```java
public class ReverseList {
    static class Node {
        int val; Node next;
        Node(int val) { this.val = val; }
    }

    static Node reverse(Node head) {
        Node prev = null, cur = head;
        while (cur != null) {
            Node next = cur.next;   // save the rest of the list
            cur.next = prev;        // flip the pointer
            prev = cur;             // move forward
            cur = next;
        }
        return prev;                // new head
    }

    public static void main(String[] args) {
        Node head = new Node(1);
        head.next = new Node(2);
        head.next.next = new Node(3);
        for (Node n = reverse(head); n != null; n = n.next) System.out.print(n.val + " ");
        // 3 2 1
        System.out.println();
    }
}
```

**Trace:** list `1 → 2 → 3`

| Step | prev | cur | After flipping |
|---|---|---|---|
| Start | null | 1 | |
| 1 | 1 | 2 | 1 → null |
| 2 | 2 | 3 | 2 → 1 → null |
| 3 | 3 | null | 3 → 2 → 1 → null |

**Complexity:** time O(n), space O(1).
**Edge cases:** empty list, single node.

## Problem 4 – Binary Search with a Boundary Case

**Problem:** find the index of a target in a sorted array, or return −1.

```java
public class BinarySearchDemo {
    static int search(int[] a, int target) {
        int low = 0, high = a.length - 1;
        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (a[mid] == target) return mid;
            if (a[mid] < target) low = mid + 1;
            else high = mid - 1;
        }
        return -1;
    }

    public static void main(String[] args) {
        int[] a = {1, 3, 5, 7, 9, 11};
        System.out.println(search(a, 7));    // 3
        System.out.println(search(a, 4));    // -1
        System.out.println(search(new int[]{}, 4)); // -1
    }
}
```

**Complexity:** time O(log n), space O(1).
**Common mistakes:** using `low < high` and missing the last element; `mid = (low + high) / 2` can overflow for very large arrays; forgetting that the array must be sorted.
